# Lorenzo Fanelli coaching site

Static site. No build step.

- `index.html`: page code, layout and design. Cesco edits this.
- `content/site.json`: text, prices, testimonials, FAQ, credentials, contact and photo paths. Lorenzo edits this in Pages CMS (https://app.pagescms.org).
- `images/`: photos. Uploads from Pages CMS land here.
- `.pages.yml`: Pages CMS editor setup.

Every commit to `main` deploys on Vercel.
